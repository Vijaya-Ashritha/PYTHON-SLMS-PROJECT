----Smart Library Management System----

Project Description:

The Smart Library Management System is a Python-based, menu-driven application that helps manage library operations. It allows users to add books, search books, issue and return books, calculate fines for late returns, and delete books. The project demonstrates the use of Python functions, lists, dictionaries, loops, conditional statements, and the datetime module.

Features :

- User Login Authentication
- Add New Books
- View All Books
- Search Book by Title
- Issue Books to Students
- Return Books
- Automatic Fine Calculation
- Delete Books
- Menu-Driven Program

Project Modules :

1. Login
2. Add Book
3. View Book
4. Search Book
5. Issue Book
6. Return Book
7. Delete Book
8. Exit
